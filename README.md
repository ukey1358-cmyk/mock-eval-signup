# 2027학년도 입학사정관 모의평가 교육 신청 시스템

울산대학교 입학관리팀 · 2026년 고교교육 기여대학 지원사업

교육 참석 차수를 사정관이 직접 선택·신청하고, 교육장 정원(30석)에 도달하면 자동으로 마감되어 다른 차수로 유도하는 신청 시스템입니다.

**관리자 화면** → https://ukey1358-cmyk.github.io/mock-eval-signup/admin.html

## 차수 편성

교육은 **1인당 2일**(1일차 종일 + 2일차 오후) 참여하므로, 한 사람이 교육장을 3개 시간슬롯 점유합니다. 매일 새 조를 받으면 오후 시간대에 두 개 조가 겹쳐 30석을 초과하기 때문에 **격일 시작 4차수**로 편성했습니다.

| 차수 | 1일차 (09:00~18:00) | 2일차 (13:00~17:00) | 정원 |
|:---:|---|---|---:|
| 1차 | 2026. 8. 24. (월) | 2026. 8. 25. (화) | 30 |
| 2차 | 2026. 8. 26. (수) | 2026. 8. 27. (목) | 30 |
| 3차 | 2026. 8. 28. (금) | 2026. 8. 31. (월) | 30 |
| 4차 | 2026. 9. 1. (화) | 2026. 9. 2. (수) | 30 |
|  |  | **총 수용** | **120** |

모든 시간슬롯이 30석 이하로 유지되며, 인정 시수는 12단위입니다.

## 구조

```
브라우저  →  GitHub Pages (정적 화면)  →  Apps Script (처리)  →  Google Sheets (저장)
```

- 서버·비용 없음. GitHub Pages와 Apps Script 모두 무료로 상시 가동됩니다.
- 정원 초과는 Apps Script `LockService` 로 신청 처리를 직렬화하여 원천 차단합니다.
- **개인정보는 이 저장소에 포함되어 있지 않습니다.** 명단은 비공개 Google Sheets에만 있으며 본인 확인은 서버에서 처리합니다.

## 설정

`config.json` 의 `apiUrl` 이 비어 있으면 **시연 모드**(브라우저 localStorage 기반 더미 데이터)로 동작하여 백엔드 없이도 화면을 확인할 수 있습니다. 시연 모드 관리자 비밀번호는 `demo` 입니다.

실제 운영을 위한 Google Sheets 생성과 Apps Script 배포 절차는 [배포 및 운영 가이드](docs/배포_및_운영_가이드.md)를 참고하세요.
