# 배포 및 운영 가이드

2027학년도 입학사정관 모의평가 교육 신청 시스템 · 울산대학교 입학관리팀

---

## 0. 전체 구조

```
사정관 브라우저  →  GitHub Pages (화면)  →  Apps Script (처리)  →  Google Sheets (저장)
```

- **화면**은 이미 GitHub Pages에 올라가 있습니다.
- **저장소와 처리**는 담당자의 Google 계정에서 한 번만 설정하면 됩니다. (아래 1~3단계, 약 10분)
- 설정 전까지는 화면이 **시연 모드**(브라우저 안에서만 동작하는 더미 데이터)로 표시됩니다.

---

## 1단계 · Google Sheets 만들기 (약 3분)

1. [sheets.new](https://sheets.new) 로 새 스프레드시트를 만듭니다.
2. 파일 이름을 `2027 모의평가 교육 신청 관리` 로 지정합니다.
3. 상단 메뉴 **[확장 프로그램] > [Apps Script]** 를 클릭합니다.
4. 편집기에 있던 기존 코드를 모두 지우고, 저장소의 `apps-script/Code.gs` 내용을 **전체 복사해서 붙여넣습니다.**
5. 저장(Ctrl+S) 후, 상단 함수 목록에서 **`setupSheets`** 를 선택하고 **[실행]** 을 누릅니다.
   - 최초 실행 시 권한 승인 창이 뜹니다. **[권한 검토] > 계정 선택 > [고급] > [(안전하지 않음) 이동] > [허용]** 순으로 진행합니다.
   - 이 스크립트는 담당자 본인의 스프레드시트에만 접근합니다.
6. 스프레드시트로 돌아가면 `명단` · `차수` · `신청` · `이력` · `설정` 5개 탭이 생성되어 있습니다.

---

## 2단계 · 명단 넣기 (약 2분)

1. `_sheet-import/명단.csv` 파일을 엽니다. (112명, 단과대학 표기 정규화 완료)
2. 헤더를 제외한 데이터 전체를 복사하여 **`명단` 탭의 2행 A열부터 붙여넣습니다.**
3. 대상은 **내부위촉사정관 112명**입니다. 전임입학사정관은 대상에서 제외되었습니다.
4. **`설정` 탭**에서 다음 두 값을 반드시 수정합니다.

| 키 | 값 | 설명 |
|---|---|---|
| `관리자비밀번호` | **직접 지정** | 초기값 `CHANGE_ME_2027` 을 반드시 변경하세요 |
| `신청마감일시` | `2026-08-22T18:00` | 필요 시 변경 (2026-08-22는 **토요일**입니다) |
| `총원` | `112` | 내부위촉사정관 112명 (전임 제외) |
| `성명확인` | `N` | `Y` 로 바꾸면 본인 확인 시 **사번+성명**을 함께 대조합니다 |

> **본인 확인 방식** — 기본값은 **사번 단독**입니다(디자인 시안 확정 사항).
> 사번만 받으면 타인의 사번을 아는 사람이 그 사람의 신청 내역(소속·차수)을 조회할 수 있습니다.
> 더 엄격하게 하려면 `설정` 탭의 `성명확인` 을 `Y` 로, 그리고 `config.json` 의 `requireName` 을 `true` 로 바꾸면
> 성명 입력란이 나타나고 두 값이 모두 일치해야 통과합니다. **두 곳을 함께 바꿔야 합니다.**

> `차수` 탭에는 4개 차수(8/24~9/2)가 이미 입력되어 있습니다. 일정 변경은 관리자 화면에서도 가능합니다.

## 3단계 · 웹앱 배포하고 URL 받기 (약 4분)

1. 다시 **[확장 프로그램] > [Apps Script]** 로 이동합니다.
2. 우측 상단 **[배포] > [새 배포]** 클릭
3. 톱니바퀴 아이콘 > **[웹 앱]** 선택
4. 아래와 같이 설정합니다.

| 항목 | 값 |
|---|---|
| 설명 | `모의평가 신청 API v1` |
| **실행 계정** | **나** |
| **액세스 권한이 있는 사용자** | **모든 사용자** |

> ⚠️ '액세스 권한'을 **모든 사용자**로 하지 않으면 사정관이 로그인 없이 신청할 수 없습니다.

5. **[배포]** 를 누르면 아래 형태의 **웹 앱 URL** 이 나옵니다. 복사해 두세요.

```
https://script.google.com/macros/s/AKfycb.................../exec
```

6. 이 URL을 담당자에게 전달하거나, 직접 반영하려면 저장소의 `config.json` 을 다음과 같이 수정하고 커밋합니다.

```json
{
  "apiUrl": "https://script.google.com/macros/s/AKfycb.../exec",
  "deadlineText": "2026-08-22T18:00",
  "venue": "울산대학교 22호관 401호 전산교육실",
  "contact": "052-259-2058"
}
```

7. 커밋 후 1~2분이면 GitHub Pages에 자동 반영됩니다. 신청 화면 상단의 `시연 모드` 표시가 사라지면 정상 연결된 것입니다.

### 관리자 화면에서 할 수 있는 일

| 탭 | 기능 |
|---|---|
| **현황 대시보드** | 차수별 확정/대기/잔여, 전체 신청률. 출석부·전체현황·식대정산 CSV 내보내기 |
| **미신청자** | 명단 대비 미신청자 자동 추출. 명단 복사 / CSV 내보내기 |
| **신청자 관리** | 차수 이동, 대기자 승급, 신청 취소 (모두 `이력` 탭에 기록) |
| **차수 · 정원 설정** | 날짜·정원·마감 여부·신청 마감일시 변경 |

### 스프레드시트에서 직접 보기

관리자 화면을 거치지 않고 스프레드시트를 열어도 동일한 데이터를 볼 수 있습니다.
`신청` 탭이 실시간 신청 현황이며, 필요하면 그대로 정렬·필터·인쇄하거나 엑셀로 내려받으면 됩니다.

## 5. 자주 있는 상황

| 상황 | 처리 |
|---|---|
| 사정관이 "명단에 없다"고 함 | `명단` 탭에서 사번이 **정확히 일치**하는지 확인 (앞자리 0·공백 주의). 필요 시 행 추가 |
| 본인 확인을 더 엄격히 하고 싶음 | `설정` 탭 `성명확인`=`Y` + `config.json` 의 `requireName`=`true` |
| 특정 차수만 몰림 | 관리자 화면 [차수·정원 설정]에서 해당 차수를 **마감**으로 전환하면 신규 신청이 차단됨 |
| 정원을 늘려야 함 | [차수·정원 설정]에서 정원 수정. 단, 좌석이 실제로 확보되었는지 먼저 확인 |
| 마감 후 추가 신청 요청 | `설정` 탭의 `신청마감일시` 를 연장하거나, 관리자가 직접 `신청` 탭에 행을 추가 |
| 코드를 수정했는데 반영 안 됨 | Apps Script에서 **[배포] > [배포 관리] > 연필(편집) > 버전: 새 버전 > [배포]** 로 재배포 |
| 신청이 몰려 오류 발생 | 정상 동작입니다. 스크립트 락이 순서대로 처리하므로 잠시 후 재시도하면 됩니다 |

## 6. 개인정보 관리 원칙

- **명단은 GitHub에 올리지 않습니다.** 사번·성명은 담당자의 비공개 Google Sheets에만 존재합니다.
- 신청 화면에는 **잔여석 집계만** 표시되며, 다른 사람의 이름은 보이지 않습니다.
- 본인 확인은 기본적으로 **사번**으로 이뤄집니다. 성명까지 대조하려면 위 `성명확인` 설정을 켜세요.
- 교육 종료 후에는 스프레드시트를 기관 보존 기준에 따라 보관하거나 파기하세요.
- `_sheet-import/` 폴더의 CSV에는 실제 명단이 들어 있습니다. **저장소에 커밋되지 않도록 `.gitignore`에 등록되어 있으며**, 사용 후에는 안전한 위치로 옮기거나 삭제하세요.
